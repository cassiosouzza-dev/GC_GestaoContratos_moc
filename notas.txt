=== GCI GESTOR PRO - VERSÃO 5.0 ===

ESTA É A MAIOR ATUALIZAÇÃO DO SISTEMA ATÉ AGORA!

🚀 DESTAQUES DESTA VERSÃO:
--------------------------------------------------
1. NOVO WORKSPACE MULTI-ABAS:
   Agora você pode abrir vários contratos simultaneamente em abas,
   facilitando a comparação e o trabalho em lote.

2. INTERFACE MODERNA E ARREDONDADA:
   Redesenhamos as abas e painéis para um visual mais limpo, 
   profissional e intuitivo (Estilo Moderno).

3. TOOLTIPS INTELIGENTES:
   Passe o mouse sobre a aba do contrato para ver instantaneamente
   o nome do Prestador e o Objeto, sem precisar clicar.

4. AUDITORIA COM IA (GEMINI):
   Integração profunda com IA para análise de riscos financeiros
   e pareceres técnicos automáticos sobre os contratos.

5. BI DINÂMICO (PIVOT TABLES):
   Nova ferramenta de análise de dados que permite criar relatórios
   estilo Excel dentro do sistema para visão gerencial.

🔧 CORREÇÕES E ESTABILIDADE:
--------------------------------------------------
- CORREÇÃO CRÍTICA: O sistema agora lembra o CPF e senha corretamente
  após atualizações, separando arquivos de dados do executável.
- PERSISTÊNCIA: Melhoria na lógica de salvamento do Banco de Dados SQLite.
- SEGURANÇA: Implementação de Ponto de Restauração (Undo) automático.
- VELOCIDADE: Otimização no carregamento inicial e transição de telas.

Aproveite as novas ferramentas de gestão!
